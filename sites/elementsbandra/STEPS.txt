# Elements Realty — Step by Step (Hindi / English)

## Docker se chalana (sabse easy)

1) Docker Desktop install karo: https://www.docker.com/products/docker-desktop/
2) Docker Desktop start karo (whale icon green hona chahiye)
3) Is folder me terminal kholo: elementsbandra
4) Command chalao:

   docker compose up --build

5) Browser me kholo:
   - Website: http://localhost:3000
   - Admin CRM: http://localhost:3000/admin/login
   - Email: admin@elementsrealty.in
   - Password: Admin@123

6) Website pe "Inquire Now" form bharo → data PostgreSQL me save hoga
7) Admin → Inquiries CRM me woh lead dikhegi

## Inquire Now data kahan save hota hai?

Form → API `/api/inquiries` → Database table `Inquiry` → Admin page `/admin/inquiries`

## Bina Docker (advanced)

1) PostgreSQL chalu rakho (ya `docker compose up -d db`)
2) `npm install`
3) `npm run db:setup`
4) `npm run dev`

## Stop

docker compose down
